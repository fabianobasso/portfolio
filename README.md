# Portfólio | Fabiano Basso Antonio

Vue 3 + TypeScript + Vite. Página única estática, publicada em https://fabianobasso.github.io/portfolio/

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera ./dist (base './', pronto para GitHub Pages)
```

- Conteúdo dos projetos: `src/assets/json/projetos.json`
- Stacks: `src/assets/json/minhas_stacks.json`
- Currículo para download: `public/Fabiano-CV.pdf` (troque o arquivo para atualizar)
